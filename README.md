# Baǵa Kyzylorda

Веб-прототип мониторинга цен на социально значимые продовольственные товары в Кызылорде.

## Запуск

### API (Django)

```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

### Интерфейс (React)

```powershell
cd frontend
npm install
npm run dev
```

Интерфейс открывается на `http://localhost:5173`, API — на `http://localhost:8000/api/`.
Демо-режим интерфейса работает и без запущенного API: использует локальный набор демонстрационных данных.

## Роли и функции

- Пользователь: карта и список торговых точек, сведения о магазине, ввод цены покупки, отправка жалобы.
- Администратор: очередь жалоб и смена статуса между «Ожидает» и «Рассмотрена».
- Цены исходно не заданы. Каждая отправленная цена хранится как отдельное наблюдение; текущая цена товара в магазине — медиана наблюдений.
- Каталог содержит 31 наименование из приложенного бюллетеня Бюро национальной статистики от 11.11.2026. Единицы отображения приведены к кг/л/шт; цены не импортировались.

## Структура

`frontend/` — React SPA с компонентами, разделёнными на функции карты, магазина, каталога, жалоб и администрирования.
`backend/` — Django REST API, доменные модели и сидер каталога/демо-магазинов.

Магазины и координаты сейчас демонстрационные, схема карты локальная и не требует внешнего картографического API. Перед эксплуатацией следует заменить демо-данные реестром магазинов и подключить геоданные города.
