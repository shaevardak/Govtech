# Baǵa Kyzylorda

Веб-прототип мониторинга цен на социально значимые продовольственные товары в Кызылорде.

## Запуск

### API (Django)

```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py makemigrations monitoring
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Один раз создайте администраторскую учётную запись в отдельном окне backend: `python manage.py createsuperuser`, затем задайте логин, e-mail и пароль. Обычный пользователь регистрируется на стартовой странице. После входа пользователь видит карту по адресу `/`, администратор — отдельную панель по адресу `/admin`.

### Интерфейс (React)

```powershell
cd frontend
npm install
npm run dev
```

Интерфейс открывается на `http://localhost:5173`, API — на `http://localhost:8000/api/`. Для регистрации, входа и работы с ценами нужен запущенный API.

## Роли и функции

- Пользователь: карта и список торговых точек, сведения о магазине, ввод цены покупки, отправка жалобы.
- Администратор: очередь жалоб и смена статуса между «Ожидает» и «Рассмотрена».
- Вход и регистрация сохраняют учётные записи в базе Django. Администраторская роль выдаётся только staff-аккаунтам.
- Цены исходно не заданы. Каждая отправленная цена хранится как отдельное наблюдение; текущая цена товара в магазине — медиана наблюдений.
- Каталог содержит 31 наименование из приложенного бюллетеня Бюро национальной статистики от 11.11.2026. Единицы отображения приведены к кг/л/шт; цены не импортировались.

## Структура

`frontend/` — React SPA с компонентами, разделёнными на функции карты, магазина, каталога, жалоб и администрирования.
`backend/` — Django REST API, доменные модели и сидер каталога/демо-магазинов.

Карта использует реальные OpenStreetMap-тайлы и требует подключения к интернету. Пока добавлена одна точка по координатам из предоставленной ссылки 2GIS (`65.525261, 44.824059`); её название и адрес в ссылке не указаны. Другие неподтверждённые точки отключены. Для загрузки полного списка социальных магазинов используйте подтверждённые адреса и координаты. Подложка показывает атрибуцию OpenStreetMap.
